Featured projects

Project 10: Detection Engineering Lab

A detection rule for SSH password guessing against many usernames, tested against labelled cases instead of just demonstrated once.

What I built
A Sigma rule for failed SSH attempts from one source across at least four distinct usernames in five minutes, converted to SQL and run in SQLite against normalized lab auth events.
Result
Four controlled failed attempts raised the alert; five scenario checks passed, including control cases. No login succeeded.
Limits
Small lab dataset. An alert marks a pattern to investigate, not proof of malicious intent.

Project 8: Centralized Logging and Detection

SSH authentication events collected through rsyslog, with a Python detector watching for brute-force patterns.

What I built
rsyslog forwarding of SSH auth events, adjusted to capture both AUTH and authpriv facilities, plus a Python detector that alerts on five failed passwords from one source in five minutes.
Result
One attempt below the threshold stayed quiet; five attempts triggered an alert.
Limits
Single VM with loopback forwarding, not a multi-host deployment.

Project 9: Network Incident Investigation

One deliberate failed SSH login, traced from packet capture to a written timeline.

What I built
A tcpdump capture of a failed SSH login from my Windows PC to the Linux Mint lab VM, correlated with journalctl auth logs into a timeline, with SHA-256 hashes recorded for evidence integrity.
Result
The evidence showed a failed attempt, not a compromise, and the report says exactly that.
Handling
Raw captures and logs are excluded from the public repo; only a sanitized report is published.

Project 11: Incident Response Triage Automation

A Python tool that turns a simulated alert into a structured case report for a human to review.

What I built
A tool that accepts simulated SSH spray alert JSON, validates fields, hashes the input and writes a Markdown case report with findings and containment recommendations for human review. It includes overwrite protection.
Limits
It reads simulated alerts only. It doesn’t inspect live logs or change system security. Raw logs and generated reports are kept out of the repo.
